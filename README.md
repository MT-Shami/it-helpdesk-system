# IT Help Desk & Ticketing Management System

A full‑stack IT support ticketing system with JWT authentication, role‑based access, and full CRUD operations for tickets.

## Features

- **Authentication** – JWT login with role claims (Employee, Agent, Admin)
- **Ticket Management** – Create, view, edit, delete tickets
- **Categories & Priorities** – Dropdowns for hardware, software, network, etc.
- **Modern UI** – Tailwind CSS, statistics cards, search, badges, responsive layout
- **Role‑Based Permissions** – Employees edit only their own tickets; delete restricted to agents/admins

## Tech Stack

- **Frontend** – React, Tailwind CSS, Axios, React Router
- **Backend** – ASP.NET Core 8 Web API, Entity Framework Core, JWT
- **Database** – SQL Server (LocalDB / SQL Express)

## Current Pages

- Login page (modern card, show/hide password)
- Employee Dashboard (stats, ticket table, create button)
- Ticket Details (two‑column conversation + info)
- Create / Edit forms
